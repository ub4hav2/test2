# NexusOS Enterprise

Коммерческое десктоп-приложение (Electron). Итоговый установщик — **один файл
`NexusOS-Setup-2.4.1.exe`**, который сам ставит программу, создаёт **ярлык на
рабочем столе** и в меню «Пуск», показывает лицензионное соглашение и
регистрируется в «Установка и удаление программ».

Важно: конечному пользователю **ничего дополнительно ставить не нужно** —
Node.js и среда выполнения уже зашиты внутрь установщика.

---

## Как получить готовый .exe

Есть два способа. Выберите один.

### Способ A — без своего Windows-ПК (через GitHub Actions) — рекомендуется

Сборка пройдёт в облаке на настоящем Windows-раннере, вы просто скачаете .exe.

1. Создайте репозиторий на GitHub и загрузите в него все файлы из этой папки
   (включая скрытую папку `.github`).
2. Откройте вкладку **Actions** → workflow **«Build Windows Installer»** →
   кнопка **Run workflow**.
3. Через 3–5 минут откройте завершившийся запуск → раздел **Artifacts** →
   скачайте **NexusOS-Installer** (внутри `NexusOS-Setup-2.4.1.exe`).

Если создать git-тег `v2.4.1`, тот же .exe автоматически прикрепится к
GitHub Release — удобно для раздачи клиентам.

### Способ B — на своём Windows-ПК

1. Установите **Node.js LTS** с https://nodejs.org (один раз).
2. Дважды кликните **BUILD-INSTALLER.bat**.
3. Готовый установщик появится в `dist\NexusOS-Setup-2.4.1.exe`.

---

## Запустить без установки (для разработки)

Дважды кликните **RUN-DEV.bat** — приложение откроется в окне Electron.

## Что сделано для коммерческого вида

- **NSIS-установщик** вместо `portable`: мастер установки с выбором папки,
  лицензионным соглашением (`LICENSE.txt`), ярлыком на рабочем столе и в «Пуск»,
  запуском приложения после установки и корректным деинсталлятором.
- Иконка приложения (`icon.ico`) для окна, установщика и ярлыков.
- Метаданные: `productName`, `appId`, `copyright`, издатель (`publisherName`).
- Автосборка на Windows через GitHub Actions (`.github/workflows`).

## Перед коммерческим релизом

1. В `package.json` и `LICENSE.txt` замените `NexusOS`, контакты и текст EULA
   на реальные данные вашей компании.
2. Для продажи без предупреждений SmartScreen подпишите установщик сертификатом
   **code signing** (OV/EV). Подпись добавляется в секцию `win` настройками
   `certificateFile`/`certificatePassword` (или через переменные окружения в
   workflow) — по запросу помогу настроить.

## Примечание о содержимом

Текущий `index.html` — интерфейс-макет: данные сканирования, карта сети и
журналы заполнены демонстрационными значениями; реальных сетевых операций
приложение не выполняет.
